# iwamatsu0430/homebrew-tap

Homebrew tap for [SockDock](https://github.com/iwamatsu0430/sock-dock-slack) — run Slack apps locally over one Socket Mode connection.

## Install

CLI (`sockdock`, built from source):

```sh
brew install iwamatsu0430/tap/sockdock
```

Menu bar app (`SockDock.app`):

```sh
brew install --cask iwamatsu0430/tap/sockdock
```

The formula and the cask can be installed side by side. The cask does not put the CLI on your `PATH`; install the formula for that.

### First launch of the app

SockDock.app is ad-hoc signed and not notarized by Apple, so macOS blocks it the first time you open it. Open **System Settings → Privacy & Security** and click **Open Anyway**.

## Contents

- `Formula/sockdock.rb` — the CLI
- `Casks/sockdock.rb` — the menu bar app

Both files are generated by the [release workflow](https://github.com/iwamatsu0430/sock-dock-slack/blob/main/.github/workflows/release.yml) of the main repository on each tagged release. Please report issues there.
