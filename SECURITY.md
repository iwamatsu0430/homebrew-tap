# Security Policy

This tap only contains Homebrew formulae and casks. A vulnerability in a packaged tool belongs to that tool's own repository (for SockDock: [iwamatsu0430/sock-dock-slack](https://github.com/iwamatsu0430/sock-dock-slack/security)).

To report a problem with the tap itself, such as a wrong download URL or checksum, use [Report a vulnerability](https://github.com/iwamatsu0430/homebrew-tap/security/advisories/new). Please do not open a public issue for security problems.
